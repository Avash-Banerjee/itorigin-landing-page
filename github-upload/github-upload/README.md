# NEXSHIELD Technologies

Marketing site for NEXSHIELD Technologies: a cybersecurity firm with twelve practices across advisory, technology and managed services.

Built with Next.js 16 (App Router), React 19, Tailwind CSS 4, Framer Motion and Lenis.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Deploy

Import this repository into Vercel. It detects Next.js automatically; no environment variables are needed.

## Before going live

Replace the placeholder email `hello@nexshield.example`, the sample figures inside the product screens, the Field notes and the engagement timings with real details. Regulatory facts were checked in November 2026; confirm them against primary sources.
